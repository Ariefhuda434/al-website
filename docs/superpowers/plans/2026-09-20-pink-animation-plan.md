# Pink Girly + Animasi + Musik — Implementation Plan

**Goal:** Menambahkan tema pink girly, animasi scroll-triggered, dan musik gratis ke portfolio.

**Architecture:** 
- CSS custom properties untuk palet pink.
- IntersectionObserver untuk animasi scroll.
- Audio element dengan kontrol mute/unmute dan playlist.

**Tech Stack:** Next.js + Tailwind + Vanilla JS (IntersectionObserver) + HTML Audio.
