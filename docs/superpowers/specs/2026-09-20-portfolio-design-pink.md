# Portfolio Kreatif — Spesifikasi Desain Pink Girly

Tanggal: 2026-09-20
Proyek: Landing Page Portfolio Kreatif (Revisi: Pink Girly + Animasi + Musik)

## Perubahan dari Spec Sebelumnya
- Palet warna: Pink sebagai primary (Soft Pink #FFC0CB, Rose Gold #E8A0BF, Cream #FFF5F7, Dark Rose #8B3A4D).
- Animasi: Scroll-triggered fade-in (IntersectionObserver), hover scale 1.03, transisi halus.
- Musik: Background music gratis (free source) dengan kontrol mute/unmute dan opsi ganti lagu.
- Layout: Single page scroll (sudah diterapkan sebelumnya, dipertahankan).

## Tech Stack (Tidak Berubah)
- Next.js 16 + React 18 + Tailwind CSS
- Firebase (Firestore + Storage)
- Vercel
