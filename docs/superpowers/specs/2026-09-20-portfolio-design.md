# Portfolio Kreatif — Spesifikasi Desain

Tanggal: 2026-09-20
Proyek: Landing Page Portfolio Kreatif (Pacar — Mahasiswa FKM)

## Tujuan
Portfolio kreatif personal branding untuk mahasiswa FKM. Menampilkan profil, skill, karya desain, usaha bunga kawat bulu, dan pencapaian.

## Struktur Halaman (Multi Halaman)
1. **Home** — Hero dengan foto besar, nama, tagline.
2. **About** — Bio singkat, foto, cerita.
3. **Skills** — Kartu skill: Public Speaking, MC, Usaha Bunga Kawat Bulu, Desain.
4. **Karya / Portfolio** — Galeri foto karya desain dan produk bunga kawat bulu (upload foto).
5. **Proyek** — Bagian proyek yang sudah dikerjakan.
6. **Testimoni** — Ulasan klien/kolega.
7. **Kontak** — Form kontak dan link media sosial.
8. **Download** — Tombol download CV/Portfolio.

## Tech Stack
- **Frontend:** Next.js (React) + Tailwind CSS
- **Database:** Firebase Firestore
- **Storage:** Firebase Storage (foto karya)
- **Hosting:** Vercel

## Desain Visual
- **Gaya:** Feminin / Lembut / Pastel
- **Palet Warna:** Cream (#FDF6F0), Soft Pink (#F4C2C2), Beige (#EDE3D5), Dark Brown (#4A3F35)
- **Font:** Font elegan (misalnya Playfair Display atau Cormorant Garamond untuk judul, Inter untuk teks)

## Fitur Utama
- Upload foto karya desain dan produk bunga kawat bulu ke Firebase Storage.
- Tampilkan skill dengan ikon/kartu.
- Form kontak sederhana.
- Tombol download CV/Portfolio.
- Bagian testimoni.
